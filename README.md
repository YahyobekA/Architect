# Артефакты Архитектора — демо 0.1

Серверный мод Fabric + Polymer для Minecraft 1.21.11 (маппинги Mojang).

## Сборка
1. Установите JDK 21 и откройте папку в IntelliJ IDEA (проект Gradle импортируется сам),
   либо выполните `gradle wrapper` и затем `./gradlew build`.
2. В `gradle.properties` проверьте `polymer_version` и `sgui_version`
   (https://maven.nucleoid.xyz, версии с суффиксом +1.21.11).
3. Готовый jar: `build/libs/architect-0.1.0-demo.jar`.

## Что в демо
- Компас слежения (ПКМ, меню с головами), магнит-помеха (ПКМ вкл/выкл, таймер, КД 10 мин)
- Разлом (Shift+ПКМ — выбор мира, ПКМ — открыть там, куда смотрите) — упрощённая версия без броска
- Исцеляющий кристалл, аметистовый кристалл, Смесь миров
- Материалы: Эссенция Пустоты, Осколок реальности (пока только через /give), Фрагмент разлома, Эссенция жизни (падают с мобов)
- Ограничение: элитра работает только в Энде
